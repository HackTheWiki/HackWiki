Markdown Guide

how we render pages, nav, and custom blocks.

how pages work

every page is a .md or .mdx file inside content/pages. the folder path becomes the url. frontmatter controls title, description, order, and section.

frontmatter fields

---
title: My Page
description: a short summary
order: 3
section: Guides
draft: false
---

navigation (markdown)

edit content/nav.md to control the header nav. use ## for group titles and list items for links.
